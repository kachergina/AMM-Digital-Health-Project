# Правила проекта AMM

## Структура проекта

```
AMMproject/
├── ru/                    — Русская версия (по умолчанию)
├── en/                    — Английская версия
├── fr/                    — Французская версия
├── assets/
│   ├── css/style.css — Единый stylesheet
│   ├── js/main.js    — Скрипт переключения языков
│   └── images/       — Изображения проекта
├── docs/            — Документация
└── pyproject.toml, requirements.txt, .gitignore
```

## Правила именования файлов

- Папки языков — `ru/`, `en/`, `fr/`
- HTML-файлы — `index.html`, `about.html`, `page.html` в каждой папке
- CSS/JS файлы в общей папке `assets/`
- Изображения в `assets/images/`
- Документация в `docs/`

## Правила HTML

- Семантическая разметка
- Язык страницы: `lang="ru"`, `lang="en"`, `lang="fr"`
- Ссылки между страницами — `ru/index.html` → `en/index.html`
- Изображения с `alt`-атрибутами

## Правила CSS

- Один файл `assets/css/style.css` для всех страниц
- Использование CSS-переменных для цветовых тем
- Адаптивность через `@media`
- Без фреймворков

## Правила добавления контента

- Новые изображения → `assets/images/`
- Новые документы → `docs/`
- Новые страницы → соответствующие языковые папки
- Проверка работоспособности ссылок перед коммитом

## Git

- Коммиты на английском языке
- Структура коммита: `Тип: описание` (например, `feat: добавить страницу`)

## Визуальная обертка (сайт)

- Сайт — статический, без бэкенда
- Все страницы — HTML + CSS + vanilla JS
- Языковая тема через CSS-переменные
- Современный минималистичный дизайн

## Переключение языков

- Навигация: **RU / EN / FR**
- Переход на язык → соответствующая папка (`/ru/`, `/en/`, `/fr/`)
- Каждая языковая папка содержит полную локализованную версию сайта
